Run **Task E** from `AGENTS.md` on the sources named, into the set named
(Set 1, `ps-g8xw`, when none is). Read `AGENTS.md` first; its rules
govern, not your judgment.

Sources and set: $ARGUMENTS

Easy to get wrong:
- Read each `raw.md` in full; derive only what the passages support.
- One line per principle, in the curator's voice, a commitment stated
  plainly. Never a quotation, never a hedge.
- One proposal per file in `maps/proposals/`, `kind: principle`, with
  `grounds` naming the source slugs it rests on and no `from_source`,
  numbered after today's highest.
- Nothing the set already holds, restated. Never a principle file, never
  an order.
- One commit for the batch: `Derive: <n> proposals for <set label>`.

When done, list each proposal (id, title, grounds) in your reply. The
curator decides each one in the app or with `/proposals`.
