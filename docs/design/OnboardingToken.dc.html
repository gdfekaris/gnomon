Create a new brain

Gnomon needs a personal access token: a password that only works for GitHub's API, which you can revoke any time. GitHub offers two kinds. Pick one and follow its steps; both work.

Fine-grained token
Classic token (simplest)

  1. On github.com, open your profile picture (top right), then Settings, then Developer settings (at the bottom of the left column), then Personal access tokens, then Fine-grained tokens.

  2. Tap "Generate new token". Name it "Gnomon phone" and set an expiry; a year is fine.

  3. Under "Repository access" choose "All repositories": the brain does not exist yet, so the token cannot be limited to it. You can swap to a single-repository token at the end of setup.

  4. Under "Permissions", then "Repository permissions", set "Administration" to "Read and write" (this lets the token create the repository) and "Contents" to "Read and write".

  5. Tap "Generate token", copy it, and paste it below. GitHub shows it only once.
