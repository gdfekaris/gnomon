Run **Task A** from `AGENTS.md`.

Input: $ARGUMENTS

If the input names no set, use Set 1. Load each selected set per "Reading
a set" in `AGENTS.md`: the framing, every principle in `order`, the
grounding passages as far as they fit.

Reason FROM the principles. They are premises, not suggestions. Cite the
principle and the passage behind each move as dual links. Where two
principles of a set pull against each other, name the tension; resolve it
only if the question requires it, in favor of the lower `order`, and say
you invoked precedence. With several sets, reason from each under its own
heading, then compare, attributing every claim to a set.

If the selected set has no principles, stop and say so.
