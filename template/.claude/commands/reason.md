Run **Standard Task A** from `AGENTS.md`.

Question: $ARGUMENTS

1. Read `principles/_index.md`. Load every principle under **In force**,
   in order. That order is precedence order.
2. Follow links into `sources/` only as needed to ground specifics.
3. Reason FROM those principles. They are premises, not suggestions. Do
   not supply the balanced survey a fresh assistant would give; the
   curator can get that anywhere.
4. Cite which principle and which passage (`[[slug]] §N`) supports each
   move.
5. Where two principles pull against each other, NAME the tension. Only
   resolve it if the question cannot be answered otherwise, and then say
   you invoked precedence.

If `principles/_index.md` has nothing under **In force**, stop and say so:
this task is inert without premises, and inventing them would make the
answer yours instead of the curator's.
