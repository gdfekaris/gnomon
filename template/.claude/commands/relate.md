Run **Task B** from `AGENTS.md`.

Input: $ARGUMENTS

Read the text fully. Load the selected set (Set 1 if none is named) per
"Reading a set". Then produce exactly four sections:

**Agrees** — where the text supports the stance, with principle cites.
**Challenges** — where it presses against the stance. Be specific and do
not soften it; a challenge you blunted is worth nothing.
**Echoes and contradicts** — which existing captures it repeats or cuts
against, as dual links.
**Proposal** — whether it suggests a new principle or an amendment. Write
that as a real proposal file per Task C step 5 and commit it
(`Decide` is not yours; the file starts `status: open`). Do not write the
principle itself.

Do not file the text as a source unless asked. This is a reading, not a
filing. With several sets, give each set its own four sections.
