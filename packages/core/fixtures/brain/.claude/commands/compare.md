description: Compare two or more principle sets (Task D)
argument-hint: --set 1 --set 2 [--set 3]
---

Run **Task D** from `AGENTS.md`.

Sets: $ARGUMENTS

Load each named set per "Reading a set". Report three sections, every
claim cited to a principle in a named set:

**Shared ground** — where the sets agree.
**Direct conflicts** — principles that cannot both be honored.
**Gaps** — questions one set answers and another is silent on.

No new text is involved. If the curator wants a text read under several
sets, that is `/relate` with several sets.
