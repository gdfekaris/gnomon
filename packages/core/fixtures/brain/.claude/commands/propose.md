Run **Task F** from `AGENTS.md` on the sources named, against the set
named (Set 1, `ps-g8xw`, when none is). Read `AGENTS.md` first; its rules
govern, not your judgment.

Sources and set: $ARGUMENTS

Easy to get wrong:
- Read each `raw.md` in full and every principle of the set; propose only
  what the passages support.
- A `link` means one thing: add the passage to that principle's grounds.
  Not for a principle that already lists it.
- An `amendment` names the principle and says in its title what should
  change. A `principle` is one the set lacks, one line, in the curator's
  voice.
- One proposal per file in `maps/proposals/`, every one with
  `target_set: <set-slug>` and `grounds`, none with `from_source`,
  numbered after today's highest. At most ten; none is fine.
- One commit for the batch: `Relate: <n> proposals for <set label>`.

When done, list each proposal (id, kind, title, target) in your reply.
The curator decides each one in the app or with `/proposals`.
