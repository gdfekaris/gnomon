Welcome to Gnomon

A second brain that lives in a private GitHub repository you own: plain files you can read anywhere, and that whichever AI you choose can reason from. This app captures into it from your phone.

You need a free GitHub account. If you do not have one yet, create it at github.com first, then come back.
