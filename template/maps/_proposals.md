# Proposals Queue

Every item has an ID, a question, and a fixed menu. **You decide by typing
a letter on the Decision line.** Then run `/proposals` and the agent
executes your decisions and deletes the finished items.

- Blank Decision = open. `/proposals` will walk you through these one at a
  time, and will not decide for you.
- You can also write free text instead of a letter if none of the options
  fit. The menu is a convenience, not a constraint.
- Agents append items here. Agents never delete an undecided item.
